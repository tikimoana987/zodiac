# Zodiaque & Décans

Signe et décan (position réelle du Soleil), zodiaque chinois, horoscope par transits, carte du ciel, compatibilité, en 7 langues.

**Utiliser l'appli : https://tikimoana987.github.io/zodiac/**

Sur iPhone : ouvrir l'adresse dans Safari, puis Partager → « Sur l'écran d'accueil ». L'appli fonctionne ensuite sans internet.

Fichiers générés par `build-standalone.py` à partir des sources du projet : ne pas les modifier à la main.
